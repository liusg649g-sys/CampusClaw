# Proposal

## Why

CampusClaw 当前支持教师上传班级材料，但学生主要通过查看或下载材料获取信息。当班级材料数量增加后，学生难以快速定位所需内容，因此需要增加限定班级范围的知识库检索能力。

本次变更旨在让用户能够在当前班级的资料范围内进行知识检索，并显示检索结果的来源信息，以提升材料查找效率，同时避免不同班级之间的数据混用。

## What Changes

- 新增班级知识库检索功能，允许用户针对当前班级的课程材料进行检索。
- 检索范围必须限定在当前班级，不允许返回其他班级的知识库内容。
- 检索结果需要支持内容溯源，显示来源文件等信息。
- 班级材料需要能够被处理为可检索的知识内容。
- 可以采用文本切分、向量化和向量检索的方式提升语义检索能力。
- 为后续接入向量数据库或向量存储方案预留实现空间。

## Capabilities

### New Capabilities

- `class-knowledge-base`: 提供限定班级范围的知识库构建与检索能力，并支持检索结果的来源追踪。

### Modified Capabilities

无。

## Impact

本次变更将影响 CampusClaw 的班级材料管理和检索流程，主要涉及后端资料处理与检索接口、班级权限过滤逻辑，以及前端知识库检索和来源展示界面。

实现过程中可能需要增加文本解析、文本分块、向量化、向量存储或语义检索相关依赖，并需要为知识内容保存班级标识和来源文件信息。
